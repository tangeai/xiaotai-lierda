# Pro 构建与固件

[产品首页](../README.md) · [烧录步骤](当前设备操作.md#build-flash) · [主机检查](../tests/README.md)

使用完整的官方 SDK 工程与产品目录，在工程根目录运行；电脑需 Python 3.10 或更高版本。可通过 `TIRTC_PYTHON` 指定 Python 路径。

```powershell
.\examples\NT26FxDx_OpenKit\tirtc_pro\build.bat
```

| 产物 | 用途 |
| --- | --- |
| 根目录 `firmware/pro/YYYY_MM_DD_HH_MM_SS_pro.binpkg` | 唯一对外出厂初始化包，包含 F6D_D 配套底包、应用及外置字库/背景文件系统；会覆盖外置 Flash 文件。 |
| 根目录 `firmware/pro/SHA256SUMS.txt` | 当前发布包校验值。 |
| `gccout/tirtc_pro/TiRTC_pro_NT26F6D0_pro_release.binpkg` | 本地完整 D 底包与应用维护包，不包含外置文件系统镜像；适合已具有正常 UI 资源的设备，不另复制或上传。 |
| `gccout/tirtc_pro_factory/` | 本地出厂镜像明细、内存映射及打包日志，不随仓库发布。 |

文件名时间取对应应用 `.bin` 的真实编译完成时间（UTC+8），不是重新命名的时间。仓库只保留根目录 `firmware/pro/` 的当前发布包与校验清单；历史包、维护包及编译中间产物不随仓库发布，产品目录下不再使用 `firmware/`。烧录时应核对所选文件的当前校验值；内部 `pro_release` 名称不代表包内容相同。由旧 A 迁移时须刷写匹配的完整 D 底包与 APP，不能只刷旧设备的 APP。烧录与擦除行为以下载工具所选项为准，维护包未包含外置镜像不等于所有存储均自动保留。

单独调试应用可执行 `examples\NT26FxDx_OpenKit\tirtc_pro\build_app.bat`，允许追加 `TIRTC_AUDIO_AEC_EN=n` 等参数，输出位于 `gccout/tirtc_pro`。此入口不会重新发布完整出厂包。独立资源安装器入口为 `examples\NT26FxDx_OpenKit\tirtc_pro\build_assets.bat`，资源源文件位于产品 `resource_store/assets14`；用法见 [资源维护](../resource_store/README.md)。

当前默认 `TIRTC_AUDIO_AEC_EN=y`、`TIRTC_AUDIO_AEC_DELAY=10`，启用利尔达 3A 的 AEC，ANS、AGC 保持旁路。`TIRTC_AUDIO_AEC_EN` 是应用音频后端开关，详细音频调试默认关闭。AI 回复期间持续采集上传，支持边播边听和云端插话打断；Pro 网络音频仍为 G.711 A-law / 8 kHz，保留原有音视频业务和音量设置。

内存和包大小以 `gccout/tirtc_pro` 的链接报告与当前产物为准。内部文件系统布局为物理 `0x3BC000..0x3E4000`（160 KiB）。
