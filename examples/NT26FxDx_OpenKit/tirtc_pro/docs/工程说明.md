## 编译入口

在完整工程根目录执行 `examples\NT26FxDx_OpenKit\tirtc_pro\build.bat`，自动选择本产品并生成包含固件与外置完整 UI 资源的出厂初始化包 `firmware/pro/YYYY_MM_DD_HH_MM_SS_pro.binpkg`。不要只下载本目录：公共 SDK、板级 Makefile 和工具链也参与构建。

官方原版工具推荐两次烧录：先选择 `_pro_assets.binpkg` 全量下载，启动设备并等待 `INSTALL_OK`，再选择 `_pro_app.binpkg` 全量下载，正常启动后确认 `LOAD_OK`。详细文件选择、顺序及错误处理见 [Pro 烧录说明](../../../../firmware/pro/README.md)。统一入口生成的 `_pro.binpkg` 合并包仅适用于已验证支持本板外置 Flash 写入的工具；该方式会覆盖外置文件系统。应用输出仍在 `gccout/tirtc_pro`，资源安装器通过 `build_assets.bat` 构建到 `gccout/tirtc_pro_assets`，详见 [资源维护](../resource_store/README.md)。

应用源码集中在 `tirtc_pro`，不引用 lite 业务。原厂 `app/demo` 使用独立分支。本板使用公共 `components/basePkg/F6D_D` 底包，产品启动、屏幕和链接兼容处理在 [board_compat](../board_compat/README.md)，TiRTC 2.5.0 库/头文件在 [sdk](../sdk/README.md)；它们是构建依赖。

## 实现边界

当前只保持一路媒体会话；AI 普通呼叫默认视频，首页电话快捷键默认语音。实时查看由平台发起，本地没有开启入口。回应声选项未接入提示音服务；当前不提供语音唤醒；默认开启 AEC，AI 回复时持续上传麦克风，支持边播边听和云端插话打断。

“多人对讲”已接入本地 `group` 模块，支持创建/加入房间、成员翻页和按住讲话。它使用 G.711 A-law 窄带音频，不包含房间视频。返回菜单会暂停媒体并保留房间关系，确认“退出房间”才提交解除关系。电话进入通话页前若位于房间页或创建/加入表单，结束后返回房间页重新同步；房间页没有主动拨号按钮。详细步骤见 [设备操作](当前设备操作.md#group)，协议与实现见 [多人对讲](多人对讲.md)。

历史 52 版的音量与清晰度反馈只适用于当时固件和场景。本次 `pro_release` 包含 Room 播放增益、入房预热、L0 静音时的 PTT 修复及对应主机检查；旧 8 kHz 样本数、尾样本补零和模拟缓冲容量的测试预期已按当前 16 kHz 硬件路径修正。根目录 `firmware/pro/` 提供配套资源安装包、正式应用包、合并包及校验清单，镜像明细和中间产物保留在 `gccout`；软件验证见 [多人对讲验证记录](多人对讲.md#validation)，双设备长时间、弱网、功能切换与真实音质仍待新包实机验收。

模块旁的 README 只说明开发接口，不再各自定义产品功能与上手步骤。软件检查的范围见以上验证记录，当前固件仍需按对应功能的操作步骤进行实机验收。
