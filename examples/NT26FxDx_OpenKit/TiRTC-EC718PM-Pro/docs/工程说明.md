## 编译入口

按[源码准备](../../../../README.md#编译与下载)下载并合入应用后，在 SDK 根目录执行 `examples\NT26FxDx_OpenKit\TiRTC-EC718PM-Pro\build.bat`，自动选择本产品并生成包含固件与外置完整 UI 资源的出厂初始化包 `examples/NT26FxDx_OpenKit/firmware/pro/YYYY_MM_DD_HH_MM_SS_pro.binpkg`。不要只下载本目录：公共 SDK、板级 Makefile 和工具链也参与构建。

PM Pro 使用原厂工具时采用两次烧录。先选择 `_pro_assets.binpkg` 全量下载，启动设备并等待 `INSTALL_OK`，再选择 `_pro_app.binpkg` 全量下载，正常启动后确认 `LOAD_OK`。详细文件选择、顺序及错误处理见 [Pro 烧录说明](../../firmware/pro/README.md)。统一入口生成的 `_pro.binpkg` 合并包包含完整外置资源镜像，写入该镜像会覆盖外置文件系统。应用输出仍在 `gccout/tirtc_pro`，资源安装器通过 `build_assets.bat` 构建到 `gccout/tirtc_pro_assets`，详见 [资源维护](../resource_store/README.md)。

应用源码集中在 `TiRTC-EC718PM-Pro`，不引用 lite 业务。原厂 `app/demo` 使用独立分支。本板使用公共 `components/basePkg/F6D_D` 底包，产品启动、屏幕和链接兼容处理在 [board_compat](../board_compat/README.md)，TiRTC 2.6.0 库/头文件在 [sdk](../sdk/README.md)；它们是构建依赖。

## 实现边界

当前只保持一路媒体会话；AI 呼叫和首页电话快捷键均使用语音。远程对讲由平台发起。回应声选项未接入提示音服务；当前不提供语音唤醒；默认开启 AEC，AI 回复播放期间暂停上传麦克风，播完后恢复。

“多人对讲”已接入本地 `group` 模块，支持创建/加入房间、成员翻页和按住讲话。它使用 G.711 A-law 窄带语音。返回菜单会暂停媒体并保留房间关系，确认“退出房间”才提交解除关系。电话进入通话页前若位于房间页或创建/加入表单，结束后返回房间页重新同步；房间页没有主动拨号按钮。详细步骤见 [设备操作](当前设备操作.md#group)，协议与实现见 [多人对讲](多人对讲.md)。

当前语音版可从[固件目录](../../firmware/pro/README.md)下载或按[构建说明](构建与固件.md)生成。源码构建的正式应用和资源安装器分别输出到两个 `gccout` 目录；SDK 的固件目录只自动发布合并包及其清单，镜像明细和中间产物也保留在 `gccout`。双设备操作见[多人对讲自查](多人对讲.md#validation)。
