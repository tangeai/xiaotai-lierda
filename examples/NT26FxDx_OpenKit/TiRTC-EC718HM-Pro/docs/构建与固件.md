# HM Pro 构建与固件

[返回 TiRTC-EC718HM-Pro](../README.md) · [固件下载与校验](../../firmware/hm-pro/README.md) · [板级配置](../boards/f9d_d/README.md)

## 1. 准备 SDK

在 Windows 上安装 Git 和 Python 3.10 或更高版本。将应用仓库和 OpenKit SDK 放在本地短英文路径中，例如 `C:\dev`。先按仓库首页下载 `Release_V0107`。已有 Lite 或 PM Pro 的同版本 SDK 时，直接使用原目录。 [公共 SDK 准备](../../../../README.md#编译与下载)

| 依赖 | 所需版本 |
| --- | --- |
| 利尔达 OpenKit SDK | 三款产品共用 `Release_V0107`（1.7.0）工作目录和工具链 |
| HM 底包及构建依赖 | 使用 SDK 自带的 `components/basePkg/F9D_D` 和对应公共头文件。 [原厂固定提交](https://github.com/lierda-iot/CAT1.bis_OpenCPU/commit/59f1250c4b8caad4bbf4f74167b7b39c79097f8c) |
| TiRTC SDK | 准备脚本从供应方取得 EC71x GCC ARM 10-2020-q4-major 的 2.5.0 mini 配套包。 [SDK 说明](../sdk/README.md) |

准备脚本将 HM 应用与 TiRTC 构建文件放在同一个 SDK 目录中，沿用原厂底包和工具链。TiRTC 压缩包约 4.55 MB。后续准备会复用校验通过的 TiRTC 依赖。

## 2. 准备应用和构建

在应用仓库根目录执行以下命令。`$sdk` 指向实际使用的 OpenKit SDK 1.7.0 目录。

```powershell
$sdk = '..\CAT1.bis_OpenCPU-sdk'
python .\tools\setup_sdk.py --product hm-pro --sdk-dir $sdk
python .\tools\setup_sdk.py --product hm-pro --sdk-dir $sdk --check
Set-Location -LiteralPath $sdk
.\examples\NT26FxDx_OpenKit\TiRTC-EC718HM-Pro\build.bat
```

若已从供应方取得相同 TiRTC 配套包，可以在准备命令中追加 `--tirtc-sdk-dir <解压目录>`，使用本地 TiRTC 文件。目录应包含 `include/tirtc/` 和 `lib/libTiRTC.a`。 [配套包说明](../sdk/README.md)

构建目标使用 `PROJECT=NT26FxDx_OpenKit`、`MODEM=NT26F9D0`、`MODEMPKG=F9D_D` 和 `BOARD_PROFILE=nt26f9d0_prodisplay`，应用包的构建版本为 `pro_f9d_d_wxav605_sdk170`，小钛平台设备档案的 `firmware_version` 为 `F9D_D_pro_0.1.0`。修改源码后重新运行准备命令再构建。

## 3. 输出和校验

以下路径均相对于准备好的 SDK 根目录。

| 构建入口 | 输出 |
| --- | --- |
| `build.bat` | `examples/NT26FxDx_OpenKit/firmware/hm-pro/YYYY_MM_DD_HH_MM_SS_hm_pro.binpkg` 及同目录的 `SHA256SUMS.txt`。 |
| `build_app.bat` | `gccout/tirtc_pro_f9d_d_170/TiRTC_pro_NT26F9D0_pro_f9d_d_wxav605_sdk170.binpkg`。 |

正式入口按应用编译完成时间（UTC+8）命名发布包。界面资源随应用内置，一个完整包用于烧录。 [发布目录说明](../../firmware/hm-pro/README.md)

构建入口会验证关键底包、驱动和头文件的 SHA-256。如果检查失败，先在应用仓库重新运行 HM 准备命令，再按报错核对 SDK 和依赖。可以用 `Get-FileHash -Algorithm SHA256` 记录本次固件摘要。 [板级 ABI 校验](../boards/f9d_d/ABI.md)

## 4. 烧录和启动核对

打开 [HM Pro 网页烧录](https://xiaotai.chat/web-flasher/?board=lierda-ec718hm-pro)，或使用适用于 NT26F9D0 的利尔达原厂下载工具。先核对设备当前底包和分区，选择下载或本次构建生成的完整 `.binpkg`。 [固件下载与校验](../../firmware/hm-pro/README.md#download)

- 原机已使用匹配的 `F9D_D` 1.7.0 和原生分区时，可通过网页或原厂工具仅更新 APP。
- 网页识别为 `F9D_D` 1.7.1 且提供重装选项时，先保存备份，再确认清除应用数据并重装为 1.7.0。完成后重新绑定设备并恢复设置。空白板、未知底包或布局无法核实时，使用利尔达针对该板卡确认的初始化或恢复流程。[烧录与迁移说明](../../firmware/hm-pro/README.md#flash)

烧录后核对所选应用包，开机确认 4G 已注册和触摸正常，再检查绑定和各功能。小钛设备档案在设备联网后更新。 [设备操作](当前设备操作.md) · [HM Pro 原厂烧录步骤](../../firmware/hm-pro/README.md#flash)
