# AI 呼叫微信与设备配置

[返回 HM Pro 产品页](../README.md) · [设备操作](当前设备操作.md#calls)

先将 HM Pro 绑定到小钛账号，建立设备联系人或完成微信小程序的来电授权。从设备通讯录手动呼叫一次，确认目标在线且能接听。

## 配置设备插件

在小钛平台打开这台设备关联的 AI 角色，启用设备插件并添加动作 `call_contact`。输入参数均为字符串。

| 参数 | 必填 | 内容 |
| --- | --- | --- |
| `target` | 是 | 通讯录中的完整名称或设备 ID |
| `contact_type` | 否 | 微信联系人填 `wechat`，设备联系人填 `device`。同名时请指定类型或使用设备 ID |
| `call_type` | 否 | 视频填 `video`，语音填 `audio`。HM Pro 缺省使用视频 |

保存角色和插件配置，重新进入设备的 AI 对话。让 AI 使用通讯录中的真实联系人，按用户要求选择通话方式。

## 在设备上使用

例如通讯录中有微信联系人“小李”，说“用语音呼叫微信联系人小李”。对应的动作参数为：

```json
{"target": "小李", "contact_type": "wechat", "call_type": "audio"}
```

固件刷新通讯录，找到唯一匹配项后会结束 AI 对话并进入通话页。找不到联系人时，先在通讯录核对名称和类型。视频通话的对端需要支持视频并开启摄像头。
