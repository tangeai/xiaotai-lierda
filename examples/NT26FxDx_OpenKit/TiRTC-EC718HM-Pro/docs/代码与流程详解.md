# 代码布局与业务流程

[返回 TiRTC-EC718HM-Pro](../README.md) · [构建与固件](构建与固件.md)

| 目录 | 职责 |
| --- | --- |
| `boards/f9d_d`、`board_compat`、`port` | 板级引脚、ABI 校验、启动、触屏和 LCD 接口 |
| `network`、`platform`、`preferences` | 蜂窝网络、平台身份和绑定流程、设置持久化 |
| `runtime`、`sdk` | TiRTC 依赖与连接适配、共享媒体资源的所有权管理 |
| `ai`、`calls`、`remote`、`group` | AI、微信和设备通话、网页实时查看、多人对讲 |
| `media`、`video` | 音频采集播放、队列与编解码，摄像头采集、JPEG 编解码和视频发布 |
| `ui`、`resources`、`resource_store` | LVGL 页面、界面资源和资源访问 |

`user_main.c` 负责初始化应用。联网和设备身份就绪后再启动平台及 TiRTC 业务。通话信令和界面根据状态机推进，音视频只在对应会话持有资源期间工作。

微信外呼按呼叫 ID 或房间号匹配建房邀请和取消通知。微信或设备来电在等待处理期间已被对方取消时，会跳过对应邀请。设备外呼可提前接受当前连接的媒体订阅，等拨号接口返回房间号、对端通过同一 RTC 连接确认该房间后，再启动采播。

视频上行从摄像头取得数据，经硬件 JPEG 编码后交给 TiRTC。下行 JPEG 经校验、入队和解码后提交给 UI。微信视频使用方形视口，右侧显示通话按键；多人房间使用音频媒体。音频工作优先于通话视频处理。
