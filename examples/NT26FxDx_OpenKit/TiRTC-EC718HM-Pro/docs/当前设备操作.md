# HM Pro 设备操作

[返回 TiRTC-EC718HM-Pro](../README.md) · [固件下载与烧录](../../firmware/hm-pro/README.md) · [构建与固件](构建与固件.md)

<a id="binding"></a>

## 联网与绑定

装入可联网的 SIM 卡并连接主天线，开机等待 4G 注册。首次启动按屏幕提示获取绑定码，在小钛平台添加设备。绑定后，可在设备的网络和运行状态页面查看注册状态和模组信息。 [小钛设备页](https://xiaotai.chat/devices)

<a id="ai"></a>

## AI 语音对话

为设备配置可用的 AI 服务，在首页点表情进入对话。屏幕显示文字内容，设备播放语音。需要通过 AI 呼叫联系人时，先在平台配置设备插件，再说出联系人及语音或视频通话方式。 [AI 呼叫配置](AI呼叫微信与设备配置详解.md)

<a id="calls"></a>

## 微信与设备通话

从通讯录选择联系人，再点语音或视频入口。微信通话需要手机小程序中的设备授权。设备互呼要求双方可联网并绑定到平台。来电页提供接听和拒绝，接通后可在通话页操作麦克风、摄像头和挂断。

视频通话时屏幕显示远端画面。和微信小程序通话使用 240×240 视频配置。首次验证时分别检查呼出、呼入、拒绝和挂断后再次呼叫。

<a id="live"></a>

## 实时查看与远程对讲

让已绑定设备停留在表情首页或时钟首页，先结束 AI 和通话，再从小钛网页的设备页发起实时查看。网页可以看设备画面并与设备语音对讲。 [小钛设备页](https://xiaotai.chat/devices)

<a id="group"></a>

## 多人语音对讲

在“更多功能 → 多人对讲”中创建房间，或输入六位房间号加入已有房间。有密码的房间还需输入四位密码。进入后默认收听，按住讲话按钮发送语音，松开结束发言。

AI、通话、实时查看和房间共享设备媒体资源。验证功能时先结束上一会话，再进入下一项。

<a id="settings"></a>

## 设置与状态

扬声器音量和麦克风增益默认都是 8/10，设置页可调节两者并独立开关。四项设置保存后重启仍生效，通话页的麦克风开关也会保存。摄像头开关只影响当前通话。“回应声”可选择女声或男声，控制进入 AI 对话时的本地“我在”提示音，重启恢复默认。

网络信息页显示注册和信号状态，运行状态页用于查看模组版本、内存和文件系统用量。应用包的构建版本为 `pro_f9d_d_wxav605_sdk170`，小钛设备档案上报的固件版本为 `F9D_D_pro_0.1.0`。
