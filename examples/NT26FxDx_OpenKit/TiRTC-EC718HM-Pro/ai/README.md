# AI 对话与联系人呼叫

设备绑定并配置 AI 角色后，可从首页进入语音对话并查看字幕。通话插件使用 `call_contact`，按联系人名称或 ID 发起请求，默认视频，也支持指定语音。配置和设备操作见 [AI 呼叫配置](../docs/AI呼叫微信与设备配置详解.md) · [设备操作](../docs/当前设备操作.md#ai)。

[tirtc_ai.c](tirtc_ai.c) 管理对话、字幕和音频会话。[ai_call_protocol.c](ai_call_protocol.c) 解析呼叫请求，匹配通讯录中的唯一联系人，再将请求交给通话模块。设备收到来电、断网或解绑时，取消已失效的请求。

AI 使用 16 kHz 单声道 Opus，上行以 20 ms 编码。设置页中的音量、麦克风增益和开关同时作用于 AI 对话。[音频适配](../media/README.md)
