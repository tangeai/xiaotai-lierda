# 音频设置

HM Pro 保存扬声器音量、麦克风增益及两者的开关。首次启动时音量和增益均为 8/10，扬声器和麦克风开启。通话页与设置页使用同一个麦克风开关。表情、息屏时间和本地回应声只在当前运行期间生效，摄像头开关只影响当前通话。[设备操作](../docs/当前设备操作.md#settings)

[tirtc_preferences.h](tirtc_preferences.h) 提供初始化、读取与更新接口。应用在启动 UI 前加载设置，后台将变更写入内部 NVM 的两个交替记录槽。设备绑定信息另行保存。切换底包并重建文件系统前请备份设置和设备数据。[烧录与迁移](../../firmware/hm-pro/README.md#flash)
