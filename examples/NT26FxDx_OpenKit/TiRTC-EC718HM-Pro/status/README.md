# 运行状态

`tirtc_status_publish()` 向界面发布独立的系统状态快照。界面邮箱初始化后，应用先发布一次，再由主任务按 5 秒周期更新。IMEI 与模组版本由独立后台任务采集，并在本次开机中缓存有效值。接通音视频通话时会推迟部分周期刷新。

| 状态 | 数据来源 |
| --- | --- |
| 时间和日期 | `liot_rtc_get_localtime()`。检查年月日与时分秒范围，读取失败或无效时显示时间未同步 |
| 模组 IMEI | 后台调用 `liot_dev_get_imei()`，仅接受以终止符结束的非零 15 位值。云平台设备 ID 由绑定模块维护 |
| 模组版本 | `liot_dev_get_firmware_version()`。后台把字符串有界复制到界面字段 |
| 音量 | `Liot_AudioGetVolume()` 读取 SDK 软件音量。实际录放音状态查看对应业务快照 |
| 事件 | 最多八条实际应用事件，包含开机后的时间并合并相邻重复项 |

状态模块使用外部 OpenCPU SDK 中 F9D_D 的 RTC、设备、音频及 RTOS 接口。事件与快照的复制在短临界区完成，硬件查询和界面发布在临界区之外。系统时钟和音量设置分别由网络、媒体与设置模块维护。[代码与流程](../docs/代码与流程详解.md) · [构建与固件](../docs/构建与固件.md)
