## 编译入口

在完整工程根目录执行 `build_tirtc.bat pro`，自动选择本产品并生成包含固件与外置字库/背景的出厂初始化包 `firmware/pro/latest.binpkg`。不要只下载本目录：公共 SDK、板级 Makefile 和工具链也参与构建。

默认一次烧录出厂包即可，**会覆盖外置 Flash 文件**。应用中间产物仍在 `gccout/tirtc_pro`；独立资源安装器 `build_tirtc_pro_assets.bat` / `gccout/tirtc_pro_assets` 仅作为维护选项，详见 [资源维护](../resource_store/README.md)。

应用源码集中在 `tirtc_pro`，不引用 lite 业务。原厂 `app/demo` 使用独立分支。本板必需的底包与兼容处理在 [board_compat](../board_compat/README.md)，TiRTC 2.5.0 库/头文件在 [sdk](../sdk/README.md)；它们是构建依赖。

## 实现边界

当前只保持一路媒体会话；AI 普通呼叫默认视频，首页电话快捷键默认语音。实时查看由平台发起，本地没有开启入口。“多人对讲”保留页面但未接入后端，回应声选项未接入提示音服务；当前不提供语音唤醒或已验证的 AEC 打断。

模块旁的 README 只说明开发接口，不再各自定义产品功能与上手步骤。当前版本的实机验证范围以发布说明为准。
