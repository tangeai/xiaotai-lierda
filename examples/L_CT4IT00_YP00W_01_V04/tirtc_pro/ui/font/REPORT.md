# UI 14 动态字幕字库修复

## 根因及修复

实物截图中“查天气□看新闻□讲笑话”的两个方框对应顿号 `U+3001`：原始打包字库有该字形，旧子集未选择它。旧生成器只保留一小组固定标点并扫描源码字符串，无法预测云端动态字幕。

生成器新增一个有界的 152 码点字幕集合，覆盖顿号、中文括号/书名号/引号、智能单/双引号、省略号、长短横线、全角 ASCII、温度、人民币/欧元和常用数学符号。10 个来源缺少的语义变体使用明确字形别名；映射见 `generation_report.json`。不引入 emoji 字库。

原有 6883 个字形的尺寸及每个像素保持一致。全部 7010 个字形均与打包原始来源或已记录的别名对应。仍使用 14px、4bpp、未压缩位图，行高 20，无新增字体栅格化任务。

生成器同时保留外置资源构建接口，`tirtc_font_set_bitmap()` 按当前位图长度检查输入；字体更新必须同步重建资源安装包。
