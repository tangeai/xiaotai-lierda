# AI 呼叫配置填写图说明

本目录图片供[AI 呼叫微信与设备配置详解](../../AI呼叫微信与设备配置详解.md)对照填写使用。

| 文件 | 内容 |
| --- | --- |
| `01-role-filled-example.png` | 自定义角色名称、描述、人设、开场白及基础选项 |
| `02-plugin-filled-example.png` | `call_contact` 插件、三行输入和两行返回 |
| `03-enable-save-bind-example.png` | 角色中启用插件、保存和绑定区域 |

图片基于 2026-09-14 公开可读取的[平台智能体页面](https://xiaotai.chat/v1/ai/agent?device_id=TIR288XNS4DM) HTML 和该页面使用的 Tailwind CSS，在本地填写说明文档中的示例值后渲染。

为了便于阅读，图片只展示相关表单区域，展开了长人设和插件描述，隐藏了无关列表，并增加黄色“离线填写示例 · 未保存 / 未绑定”标记。表单字段、参数列、插件开关和按钮文案以获取时的页面代码为依据；参数描述单行显示不全时，完整内容见正文表格。

原页面的网络请求脚本和事件处理已移除；没有读取登录态、账号角色、联系人、音色列表，也没有创建服务器插件、保存角色或绑定设备。图中本机 ID 来自用户提供的配置网址；“小钛通话助手”“妈妈”“小李”等为文档示例。

这些图片不代表设备已经配置成功或通话已验证。实际生效结果应在平台保存、刷新，并在设备新 AI 会话中检查。平台界面属于探鸽小钛；本目录没有把网页代码重新发布为工程业务代码。
